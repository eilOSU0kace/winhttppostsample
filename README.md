### server-api

Members of the Vintageous team can obtain `config/pickby.key` from a teammate, or generate a new one:

```bash
openssl rand -hex 32 > config/pickby.key
```

This unlocks `config/entities.enc`. Set `MINTEK_SECRET` temporarily to edit portfinder credentials:

```bash
MINTEK_SECRET=placeholder async3 credentials:edit
```

No changes required — async3 generates a proper `mergewith_base` for you on save.

### mcts

After installing Python and SQLite:

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py loaddata winsta
python manage.py runserver
```
